# Site vitrine OBM — Positionnement BTP + Auto/IA

Site vitrine one-page autonome, généré le 30 juin 2026 avec le nouveau positionnement (spécialiste BTP, signature : structurer + automatiser).

## Ouvrir

Double-cliquer sur `index.html` (s'ouvre dans le navigateur). Aucun serveur ni dépendance, tout est dans le fichier (seule la police Inter est chargée depuis Google Fonts).

## Contenu

- Hero (accroche + 2 boutons d'appel)
- Problème (4 cartes, douleurs patron BTP)
- Solution (avant / après)
- À propos (parcours terrain, phrase histoire)
- Services (4 piliers : auto/IA, gestion de projet, outils, accompagnement)
- FAQ (5 questions, accordéon)
- Call to action + formulaire de contact
- Footer
- Section témoignages : **masquée** au lancement (à réintégrer après les premiers clients)

## À faire avant mise en ligne

1. **Photo** : remplacer le bloc visuel "à propos" par une vraie photo (zone `.about .photo`).
2. **Formulaire** : aujourd'hui en démo (alerte JS). À connecter à un email, un Calendly/Cal.com, ou un outil de prise de rendez-vous.
3. **Coordonnées** : ajouter téléphone / email réels dans le footer si souhaité.
4. **Témoignages** : réintégrer la section une fois les premiers clients acquis.

# Mon équipe IA

## Agents principaux

### 📋 Operations
Rôle : organiser les projets, préparer les roadmaps, créer les procédures, suivre les missions et coordonner les opérations.
Futur fichier technique :
`.claude/agents/operations.md`
Statut : à construire en priorité.

### 📞 Sales
Rôle : gérer la prospection, les interviews découverte, les appels stratégiques, les offres, les objections et les relances.
Futur fichier technique :
`.claude/agents/sales.md`
Statut : à construire après Operations.

### ✍️ Marketing
Rôle : travailler le positionnement, LinkedIn, Instagram, les contenus, les messages et la communication.
Futur fichier technique :
`.claude/agents/marketing.md`
Statut : planifié.

### ⚙️ Automation
Rôle : concevoir et améliorer les automatisations avec n8n, Airtable, les API, les MCP et les outils IA.
Futur fichier technique :
`.claude/agents/automation.md`
Statut : planifié.

### 📊 Business
Rôle : suivre les objectifs, les indicateurs, la rentabilité, les offres et le développement de l'activité.
Futur fichier technique :
`.claude/agents/business.md`
Statut : planifié.

### 📚 Knowledge Manager
Rôle : analyser les nouvelles ressources, les résumer, les classer, repérer les doublons, créer des liens et proposer leur transformation en Knowledge, Template, SOP ou Skill.
Futur fichier technique :
`.claude/agents/knowledge-manager.md`
Statut : à construire lorsque la base documentaire sera suffisamment remplie.

## 🎯 Futurs agents spécialisés

Cette section accueillera les futurs agents créés selon les besoins réels de Christophe et de ses clients.
Aucun nouvel agent ne doit être créé sans définir clairement :

1. son rôle ;
2. ses responsabilités ;
3. les ressources qu'il peut utiliser ;
4. ce qu'il n'a pas le droit de faire ;
5. sa différence avec les agents existants.
